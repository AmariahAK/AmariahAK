## Flagship: Atlarix

> A native desktop AI coding environment for developers who want real
> architectural understanding, not just autocomplete.

**v8.0.4** · Mac + Linux · [atlarix.dev](https://atlarix.dev) · 

Atlarix parses your codebase into a live Blueprint graph via Round-Trip
Engineering, then uses that graph as RAG for every AI query — reducing token
usage from ~100K to ~5K per query. v8 ships model-triggered context compression,
a community Skills Marketplace, streaming guarantees, BYOK error banners, and
~50% fewer input tokens per turn vs v7 (verified via OpenRouter logs).

**v8 highlights:**
- `compress_context` tool — model decides when to compress, not a timer
- Skills Marketplace — browse 30 community skills from an open registry
- Context cleanup — 6 pre-dispatch injections removed, 18K → 8K tokens/turn
- Streaming terminal guarantee — no more stuck loading states
- BYOK error banners — 401/429/404/network classified with fix suggestions
- Explore subagent — dedicated read-only codebase exploration via delegation
- OpenRouter app identification — shows as "Atlarix" not "Unknown"

**Foundations (v7):**
- Parallel agents: Research · Architect · Builder · Reviewer · Debugger
- Task ledger surviving context resets
- Tree-sitter AST parsing with regex fallback
- Compass managed tier — no API key required (Fast / Balanced / Thinking)
- Full CI/CD with Apple Notarisation + Linux packaging
- Three-tier subscription (Free / Pro $19/mo / Workforce $79/mo)

Multi-provider: OpenAI · Anthropic · Gemini · Groq · Mistral · xAI · OpenRouter · Ollama · LM Studio

**Winner — Amazon Nova AI Hackathon (Devpost × AWS)** · Red Bull Basement Global Innovation Programme
